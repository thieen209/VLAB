Current Android prototype: **0.1.3/code4**, Android8+, ARMv7+ARM64. [Download APK](https://github.com/thieen209/VLAB/releases/download/v0.1.3-secondtest-20261020/VLAB-0.1.3-android.apk).

Android Build Support/SDK/NDK/OpenJDK required. Release signing uses private environment values; keys and APKs stay out of Git. Supplied assets/packages/fonts retain their respective notices.

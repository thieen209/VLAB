## Concrete defect corrected

`ExperimentSession.Record` previously created a new list containing the same mutable Reading objects as the live ModelResult. Changing a live reading value, key, unit or bilingual label consequently changed an existing AttemptRecord in memory. This violated observation snapshot isolation even though immediate save/reopen tests passed.

The integrated fix deep-copies every Reading field while preserving the existing immutable provenance strings and separately copied parameter array. `SubjectRecordVerifier.VerifyReadingIsolation` mutates the live reading and verifies the record, restores it, then mutates the recorded reading and verifies the live measurement; finally it restores both. The regression runs for every recorded native journey, before file persistence checks.

Integrated sources: `Assets/VLABProduct/Scripts/ExperimentSession.cs` (Record method) and `Assets/VLABProduct/Scripts/SubjectRecordVerifier.cs`. The fix changes record ownership rather than apparatus geometry, driver controls or scientific outputs.

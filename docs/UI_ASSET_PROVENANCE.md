# UI asset provenance

The user's main.pdf sketch, page1, defines the Home composition. The supplied Beat Saber screenshot is a visual reference only; no Beat Saber artwork, logo, font or game assets are included in this product. See MENU_ART_DIRECTION.md for the comparison and acceptance contract.

Home scientific elements are original native Unity vector geometry in SciencePortalGraphic.cs. Cards and controls use runtime meshes and existing Unity UI components. The rejected generated classroom and SubjectHeroes-v1 atlas are excluded from the current project and publication checkout.

The current contour treatment subtracts real card-surface geometry and removes the intersected outer-frame segments, opening lower/right crossings to the exterior. It does not place a complete rectangle behind an overflowing symbol. Titles are top-centred; the palette uses muted slate and warm light strokes. The Home card face follows the saved UI opacity, default80% for new/default settings and adjustable55–100%; explicitly saved choices are retained. The connected six-category Settings rail is composed from one rounded Unity UI host, six transparent hit areas and a selected underline, with no imported segmented-control artwork.

Home and four subject backgrounds are captures of the actual current-project FourLabs rooms. LabPanoramaCapture renders a derived static image without saving changes to the source scenes or instrument geometry. A four-iteration separable Gaussian blur is baked in the Editor; the runtime panorama needs no live blur passes. Hover chooses the corresponding room photograph. The source room, furnishing and instrument licenses remain in shipped credits.

The transparent VLAB identity is the user's original supplied artwork. Its source pixels are preserved; transparent bounds are used for horizontal alignment, and the current composition lowers its position within the upper brand area. There is no black backing rectangle.

## Controller illustrations

`Resources/UI/ControllerPair-v3.png` and `ControllerSide-v1.png` were generated with the image-generation tool at the user's request, using their controller-reference material for approximate physical form. Front/side views preserve transparent backgrounds and use matching graphite controls. Unity crops their UV rectangles for each hand without rewriting source pixels. The illustrations locate buttons; they do not certify the hardware design, firmware HID identifiers, hand separation or BLE protocol.
